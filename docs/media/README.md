# BarPocket v0.8 demo

barpocket-demo.mp4: approved 42-second landscape demo, 1920×1080, 30 fps, silent English captions. barpocket-preview.gif: a 13-second excerpt showing native menu activation and two-way movement, 720 px wide, 10 fps.

The desktop and pointer actions are animated. Docker, Wi-Fi, Battery and Spotlight artwork comes from native menu bar window stills; relative point sizes are retained. The example app uses an AppKit SF Symbol with red/green status badges. Its menu is a native NSMenu captured after activation through BarPocket. Settings images are renders of the production AppKit views in light and dark appearance. Badge timing illustrates sampled updates, rather than a live recording of another app.

Big Sur desktop wallpaper is from Apple's original system wallpaper package. Other system glyphs were exported with AppKit SF Symbols. No private desktop or corporate application menus are included. The omitted divider is a presentation choice; the installed app uses a divider to hide native items.

Requirements, permissions and compatibility limits are described in the main README and release audit. This is an experimental source release, not a notarized app download.
